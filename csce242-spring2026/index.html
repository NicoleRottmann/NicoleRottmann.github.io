Assignments

Assignment 1: Basic HTML

Build a complete webpage from scratch using properly structured HTML. The page must include headings, multiple paragraphs, images, a list, a table, and external links, along with correct formatting, comments, and required document structure.

Assignment 2: Basic CSS

Create and style a webpage linked from your main index page using an external stylesheet. Apply basic CSS concepts to change fonts, establish a cohesive color scheme, add backgrounds, format a readable content container, style images and tables with borders and padding, customize link appearance, and use element selectors and IDs with proper formatting and comments.

Assignment 3: Page Layout

Create a responsive webpage that matches the provided layout diagrams for large and small screens using semantic HTML elements and Flexbox. Use a media query to switch the navigation between horizontal (large screens) and vertical (small screens), ensuring margins and spacing match the diagrams.

Assignment 4: Recreate CSS Page

Recreate the provided webpage layout using HTML and CSS, focusing on matching the structure, colors, and overall design. Replace original text and images with placeholders, and use Flexbox to achieve a responsive layout that works on both large and small screens. The goal of this assignment is to practice accurately reproducing a given layout using Flexbox.

Project

Part 1: Topic Selection

Artistry Online is a digital gallery website designed to showcase artwork from a variety of artists, time periods, and mediums, including paintings, sculptures, and digital works. Users can explore detailed artwork and artist profiles while registered users build a personal collection by saving their favorite pieces. The site aims to make art more accessible to a global audience while combining visual presentation with interactive features and data-driven functionality.

Part 2: Wireframes -Home Page

Create a professional wireframe for the home page of your project using Figma, focusing on clean layout, consistency, and visual hierarchy. Use AI-generated images and text that fit your website’s theme, and design a complete, polished homepage that fully fills the screen. Submit a PDF of the wireframe, add it to your projects section, and include a short video walkthrough of your Figma file showing all layers.

Part 2: Wireframes - Video

Create a youtube video demonstrating how your Figma prototype was created, showcasing each layer and the elements within it. Upload the video to Youtube.

Part 3: Wireframes Complete

Design and wireframe every page of your website so it looks polished, complete, and visually consistent, using AI-generated images and text that match your theme instead of placeholders. Your homepage and detail pages should feel professional and fully developed, with careful attention to alignment, spacing, color consistency, and navigation behavior so nothing shifts or feels unrefined.

Part 3: Wireframes Complete-Video

Create a youtube video demonstrating how your Figma prototype was created, showcasing each layer and the elements within it. Upload the video to Youtube.

Part 4: Artistry Online - Homepage

Implement your homepage from the wireframes in HTML and CSS so it is pixel-perfect (or improved), incorporates all required colors and images using CSS variables, reflects all suggested revisions, and looks great at every screen resolution.

Part 5: All Pages Complete

Implement all remaining pages from the wireframes in HTML and CSS so it is pixel-perfect, ensuring the first item of each gallery is clickable.It must look great at every screen resolution. Use JavaScript to hide/show and toggle navigation!
